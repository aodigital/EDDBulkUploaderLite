== Description ==

**Bulk Uploader & Importer for Easy Digital Downloads - Lite** simplifies the process of managing your digital products with essential bulk management tools. This free version allows you to efficiently upload, organize, and import items into your Easy Digital Downloads (EDD) store.

### Key Features
* **Bulk Upload**: Quickly upload images and videos to prepare EDD items.
* **Tag and Category Management**: Add or remove tags and categories in bulk.
* **Pricing Updates**: Bulk update pricing for multiple items at once.
* **Easy Integration with EDD**: Process bulk imports of new download items.
* **Amazon S3 Integration**: Upload files to your Amazon S3 bucket for secure storage.

### Unlock Advanced Features
Upgrade to the premium version at [this link](https://aodigital.com.au/downloads/edd-bulk-uploader-importer-full/) to access powerful tools like:
* Image renaming.
* Image watermarking.
* Automatic tag extraction from metadata.
* AI-powered tools for generating titles, descriptions, and tags using Google Vision and OpenAI.
* More advanced features coming in future updates!

== Installation ==

1. Download and install the plugin through the WordPress plugin repository or upload it manually to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Start managing your digital products using the plugin’s intuitive interface.
